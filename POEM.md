# Three Tiers of Code

A browser calls to Next.js bright,
On port three-thousand, shining light,
React and Tailwind dance as one,
The frontend's work has just begun.

Down flows the request, swift and true,
To Express on thirty-oh-one's queue,
Node.js handles every call,
The API stands proud and tall.

Then deeper still, the data flows,
To PostgreSQL where knowledge grows,
Migrations guide the schema's way,
Through node-pg-migrate's careful play.

Docker Compose orchestrates the song,
Four services working all day long,
Postgres waits, then migrate runs,
Before the API and web have fun.

A task manager, simple yet complete,
Shows how the three tiers neatly meet,
From browser down to database deep,
A reference that developers keep.

And when it's time to scale and grow,
To Google Cloud the code will go,
Terraform builds the infrastructure high,
Cloud Run and Cloud SQL in the sky.

Three layers, one vision, clean and clear,
An example that we all hold dear,
A blueprint for the web to see,
How architecture ought to be.
