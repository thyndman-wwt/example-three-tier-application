# A Poem for the Three-Tier Application

## Layers of Code

Three tiers stand tall, a tower of grace,
Each layer in its rightful place,
From browser to database deep,
A symphony of promises to keep.

**The Frontend sings** in Next.js bright,
React and Tailwind, pure delight,
On port 3000, the user's view,
Where tasks are born and dreams come true.

**The API speaks** in Express tongue,
Node.js melodies, forever sung,
On port 3001, the bridge between,
The finest REST API you've seen.

**The Database holds** the truth so deep,
PostgreSQL's secrets safe to keep,
Seventeen strong, it stores the way,
Every task from night to day.

Docker Compose orchestrates the dance,
Four services in perfect stance,
Postgres waits, migrations flow,
API and web begin to glow.

From local machine to Google Cloud,
Terraform speaks clear and loud,
Cloud Run and Cloud SQL aligned,
Infrastructure of the finest kind.

A task manager, simple yet profound,
Where three-tier architecture is found,
This example shows the path so clear,
For building apps that engineers hold dear.

*Written in celebration of the example-three-tier-application repository.*
