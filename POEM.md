# A Poem About the Three-Tier Application

## Three Tiers of Code

In layers stacked, a structure grand,
Three tiers rise across the land,
Where frontend meets the backend's call,
And data flows through them all.

### The Frontend Gleams

At the top, Next.js does shine,
React components, so divine,
With Tailwind's colors, crisp and clean,
The prettiest interface you've seen.
On port three-thousand, users browse,
Through tasks and todos, making vows,
A modern web app, fast and bright,
Rendering pages, left and right.

### The API Stands Tall

In the middle, Express takes its place,
A Node.js server, keeping pace,
On port three-thousand and one it waits,
Handling requests at the gates.
RESTful endpoints, clean and clear,
`/tasks` and `/health` appear,
Creating, updating, with grace and care,
Bridging the frontend and database there.

### The Database Holds True

At the foundation, PostgreSQL stands,
Holding the data in steady hands,
Seventeen versions, strong and wise,
Where all the truth and records lies.
Migrations flow like water's stream,
Keeping the schema in perfect dream,
Each task, each todo, safely stored,
In tables organized and poured.

### Docker Composes the Symphony

And Docker Compose brings them all,
In harmony, answering the call,
Four services dance in perfect time,
Postgres, migrate, API, and the sublime,
The web frontend, the final piece,
Bringing the user their sweet release.
From localhost to the cloud so high,
Terraform helps the app to fly.

### A Task Manager's Tale

Simple yet elegant, the app does show,
How three tiers work, and how they flow,
A task manager, humble and true,
Demonstrating what great code can do.
From browser to server, to database deep,
The architecture's promises to keep,
A reference implementation, clear and bright,
Guiding developers through the night.

*A tribute to the example-three-tier-application repository, where architecture meets poetry.*
