# A Poem About This Repository

## Three Tiers of Code

In layers three, a structure stands so tall,
A symphony of services, answering the call.
Next.js in the browser, React's graceful dance,
Where users interact with every glance.

Express flows between, a bridge so true,
Port 3001 carries requests through and through.
RESTful endpoints, clean and well-designed,
Tasks created, updated, and refined.

PostgreSQL waits below, steadfast and strong,
Storing every task where it belongs.
Migrations guide the schema's gentle change,
A database that's stable, never strange.

Docker Compose orchestrates the whole affair,
Four services spinning with meticulous care.
Postgres awakens first, then migrate runs,
API and web follow—the dance has begun.

From localhost to Google Cloud it flies,
Terraform provisions beneath the skies.
Cloud Run and Cloud SQL, a managed embrace,
Infrastructure as code, in its rightful place.

A task manager simple, yet profound in design,
Where frontend and backend and database align.
Three tiers of excellence, working as one,
A reference implementation, beautifully done.

So here's to this repo, a template so fine,
Where architecture and code perfectly combine.
A guide for the builders, a beacon so bright,
A three-tier application, built just right.
