# A Poem for the Three-Tier Application

Three layers dance in harmony,
A symphony of code and data free,
Where frontend meets the backend's call,
And databases hold it all.

**The Frontend speaks in React's sweet tongue,**
Next.js renders pages, fresh and young,
Tailwind paints with colors bright,
Port 3000 glows with morning light.

**The API stands as middle ground,**
Express routes where logic's found,
Node.js flows with steady grace,
Port 3001 is its place.

**PostgreSQL sleeps beneath the ground,**
Where every task and truth are found,
Migrations shape the schema's form,
Data safe and data warm.

From browser to the database deep,
A journey that the layers keep,
Docker Compose orchestrates the dance,
Each service gets its rightful chance.

In GCP the trio flies,
Cloud Run carries them to skies,
Terraform builds the infrastructure strong,
Where three-tier apps belong.

A task manager, simple yet complete,
Shows how the three-tier layers meet,
To-do lists rise and fall and flow,
Through the tiers, high and low.

So here's to code that's well-designed,
With separation on the mind,
Three tiers working as one whole,
Each layer playing its vital role.
