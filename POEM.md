# A Poem About This Repository

## Three Tiers of Code

In layers three, a structure stands so tall,
Where frontend, backend, database enthrall,
A symphony of services working as one,
From browser to database, the journey's begun.

Next.js greets the user with a gleaming face,
React components dancing through cyberspace,
Tailwind CSS paints the colors bright,
On port 3000, a beautiful sight.

Express awaits on port 3001's door,
Node.js handling requests galore,
REST endpoints crafted with care and grace,
The API's the heart of this digital space.

PostgreSQL stands as the keeper of truth,
Storing the data, the digital proof,
Migrations flow like water so clear,
Schemas evolving year after year.

Docker Compose orchestrates the dance,
Four services given their chance,
Postgres, migrate, api, and web,
Each one a thread in the digital web.

From local machines to Google's cloud,
Terraform speaks its infrastructure loud,
Cloud Run and Cloud SQL in harmony blend,
A deployment that scales without end.

A task manager simple, yet profound,
Shows how three tiers work around,
Communication flowing from tier to tier,
Making the architecture crystal clear.

So here's to the code, the structure, the art,
Three tiers together, each playing their part,
A reference implementation, a guide for the way,
To build applications that scale every day.
