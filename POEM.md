# A Poem About the Three-Tier Application

Three layers dance in harmony,
A web app built for all to see,
Next.js and React paint the view,
With Tailwind's grace in every hue.

Express stands guard in the middle ground,
Where API endpoints can be found,
Node.js flows through every request,
Routing tasks with careful zest.

PostgreSQL waits down below,
Where data streams and queries flow,
Migrations guide the schema's way,
Building structure day by day.

Docker Compose brings them to life,
Orchestrating without strife,
Four services in perfect time,
A symphony of code sublime.

From localhost to the cloud so high,
Terraform helps the app to fly,
Google Cloud Platform takes the stage,
Cloud Run and SQL turn the page.

A task manager, simple and true,
Shows how the three tiers work for you,
Frontend, API, database deep,
A reference design we all can keep.
