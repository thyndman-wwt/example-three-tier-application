# A Poem About the Three-Tier Application

Three layers rise in harmony,
A tower built for all to see,
From browser to the database deep,
Where tasks and data safely keep.

At the top, Next.js shines so bright,
React and Tailwind, pure delight,
Port 3000 welcomes every guest,
A frontend crafted with the best.

Below it lies Express so true,
Node.js twenty-two, tried and new,
On port 3001, it stands its ground,
Where REST endpoints can be found.

And at the base, PostgreSQL waits,
Seventeen strong, it guards the gates,
Each task and todo stored with care,
In columns, rows, beyond compare.

Docker Compose brings them to life,
No installation, no strife,
One command starts the whole machine,
The cleanest stack you've ever seen.

From local development to the cloud,
Terraform speaks clear and loud,
Google Cloud Platform takes the stage,
Cloud Run and SQL, the modern age.

Migrations flow like gentle streams,
node-pg-migrate fulfills our dreams,
Schema changes, smooth and neat,
Making the architecture complete.

A reference for the world to learn,
How three tiers work and turn,
Frontend, API, database true,
An example built for me and you.

So here's to this application grand,
A three-tier tower, carefully planned,
Where code and infrastructure meet,
Making web development complete.
