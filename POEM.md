# A Poem About the Three-Tier Application

**Layers of Purpose**

Three tiers rise like a tower of code,
Each layer bearing its own load,
A symphony of services, carefully designed,
Where frontend, backend, and database bind.

At the top, Next.js and React dance bright,
Tailwind CSS paints the user's sight,
Port 3000 opens to the browser's view,
A task manager, simple and true.

Below it lies Express, steady and strong,
Port 3001 hums its API song,
Node.js flows through its veins with grace,
Handling requests at a measured pace.

And deeper still, PostgreSQL waits,
The keeper of data, the guardian of fates,
Seventeen versions deep in the ground,
Where every task and truth is found.

Docker Compose orchestrates the dance,
Postgres, migrate, api—each gets its chance,
Health checks ensure the foundation is sound,
Before the next layer can come around.

From local machines to Google's cloud,
Terraform speaks its infrastructure loud,
Cloud Run and Cloud SQL join the show,
A three-tier dream, from dev to pro.

Browser to API to database deep,
A cycle of service, a promise to keep,
This example application, so clean and so clear,
Shows how great systems are engineered here.
