# A Poem for the Three-Tier Application

## Three Tiers of Code

In layers deep, a structure stands so true,
Three tiers of code, each with work to do.

**The Frontend sings** in React and Next.js light,
With Tailwind's grace, it paints the user's sight,
On port three-thousand, the browser finds its way,
Where tasks are born and managed every day.

**The API speaks** in Express, clear and strong,
On port three-thousand-one, it hums along,
A REST-ful voice that listens, answers, guides,
The bridge between the front and where data hides.

**The Database sleeps** in PostgreSQL's embrace,
Seventeen versions deep in Docker's space,
Where every task is stored with careful hand,
A source of truth on which we firmly stand.

From browser to API, from API to store,
The three tiers dance, forever wanting more,
With Docker Compose they rise as one,
And on the Cloud they run and run and run.

Through Terraform's design on Google's ground,
A scalable solution can be found,
From local dev to production's gleaming height,
This three-tier app shines ever bright.

So here's to code that's layered, clean, and wise,
A reference for all who seek to rise,
Three tiers of power, working in accord,
A task manager's symphony, beautifully stored.
